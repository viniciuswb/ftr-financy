# Financy Front-end Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A React app in `frontend/` that matches the Figma screens and lets each user manage their own transactions and categories through the existing GraphQL API.

**Architecture:** Vite + React + TypeScript SPA. Pure logic (money, dates, filters, summaries) lives in small tested modules; UI components mirror the Figma Style Guide; pages compose them. Apollo Client talks to the API with a Bearer token from a Zustand auth store; both lists are refetched after every mutation. Served by nginx in Docker next to the API.

**Tech Stack:** React 19, TypeScript 5.9, Vite 8, Tailwind CSS 4, Radix (via `radix-ui`) styled shadcn-style, Apollo Client 4, Zustand 5, React Router 7, React Hook Form 7 + Zod 4, sonner, lucide-react, react-day-picker 9, Vitest 4 + Testing Library.

**Spec:** `docs/superpowers/specs/2026-10-27-frontend-design.md`

## Review Focus

1. Picking a date in the calendar (any timezone, any hour) must send exactly that day as `YYYY-MM-DD` and show it back unchanged — no off-by-one from UTC conversion. Tests in Tasks 2 and 7.
2. Currency input: clearing every digit, typing letters, or pasting `1.234,56` must never produce `NaN` or a negative; an empty value is rejected with "Valor deve ser maior que zero". Tests in Task 3 and Task 7.
3. Search ignores case and accents both ways: `saude` finds "Saúde", `SALÁRIO` finds "Salário". Test in Task 7.
4. Deleting the last row of the last page must show the previous page, not an empty page; changing a filter returns to page 1. Test in Task 7.
5. A session that expires mid-use logs out once (one toast, one redirect), while a wrong password on Login shows only "E-mail ou senha inválidos" and never "Sessão expirada". Test in Task 4.
